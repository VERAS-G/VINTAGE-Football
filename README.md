# VINTAGE — Football Heritage

Frontend ecommerce demo in HTML, CSS and JavaScript, based on the supplied specification.

## Run
Open `index.html` directly, or use VS Code Live Server for the best experience.

## Structure
- `index.html` — cinematic home
- `pages/produtos.html` — collection, search/filter/sort
- `pages/produto.html` — dynamic product page
- `pages/carrinho.html` — persistent cart
- `pages/checkout.html` — 4-step demo checkout
- `pages/pedido-confirmado.html` — generated order confirmation
- `css/` — styles separated by concern
- `js/` — product data, navigation, animations, search, cart and checkout
- `assets/` — image/icon folders and attribution file

## Technologies
- HTML5 / CSS3 / Vanilla JavaScript
- GSAP + ScrollTrigger via CDN
- Lenis via CDN
- localStorage for cart persistence
- `prefers-reduced-motion` support

## Important
The project is frontend-only. PIX/card screens are demo UI; no real payment is processed.
